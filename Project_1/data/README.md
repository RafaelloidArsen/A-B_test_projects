# Данные: Brazilian E-Commerce Public Dataset by Olist

Реальные данные бразильского маркетплейса Olist: ~100 000 заказов за 2016-2018 гг.
(заказы, покупатели, продавцы, товары, платежи, отзывы, геолокация) — 9 связанных CSV-файлов.

## Откуда скачать

Kaggle — **"Brazilian E-Commerce Public Dataset by Olist"**:
https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce

## Как разместить

Скачайте архив и распакуйте CSV-файлы в эту папку (`Project_1/data/`). Ожидаемые файлы:

- `olist_orders_dataset.csv`
- `olist_order_payments_dataset.csv`
- `olist_customers_dataset.csv`
- `olist_order_items_dataset.csv`
- `olist_order_reviews_dataset.csv`
- `olist_products_dataset.csv`
- `olist_sellers_dataset.csv`
- `olist_geolocation_dataset.csv`
- `product_category_name_translation.csv`

> Сами CSV не хранятся в git (см. `.gitignore` в корне репозитория).
