# Анализ данных и проверка гипотез

Учебные проекты по продуктовой аналитике и проверке статистических гипотез на Python
(pandas, numpy, scipy, statsmodels, matplotlib, seaborn).

Репозиторий сознательно разделяет два типа задач:

- **Project_1, Project_2 — наблюдательные сравнения** реальных данных. Группы НЕ
  формировались случайным сплитом, поэтому это **не A/B-тесты**: выводы описательные,
  возможны конфаундеры, причинность не устанавливается.
- **Project_3 — настоящие рандомизированные A/B-тесты** на синтетических данных со
  случайным распределением по группам: расчёт размера выборки, MDE, мощности и
  корректная интерпретация.

## Проекты

### Project_1 — Olist (Brazilian E-Commerce)
Продуктовые метрики бразильского маркетплейса: выручка, ARPPU, сезонность, попытка
когортного анализа и наблюдательное сравнение среднего платежа по способу оплаты
(кредитная карта vs ваучер). Различие значимо и практически заметно (Cohen's d ≈ 0.45),
но данные наблюдательные. Отдельно показано, что Retention на этом датасете построить
нельзя: каждый покупатель делает ровно один заказ.
Ноутбук: `Project_1/notebooks/01_eda.ipynb`.

### Project_2 — Online Retail II
Метрики британского онлайн-ритейлера, корректный ARPPU (выручка = `Quantity * Price`
на очищенных данных), полноценная **когортная матрица Retention** и наблюдательное
сравнение групп по стране (UK vs Германия). Показателен вывод: при огромной выборке
p-value ничтожно мал, но **размер эффекта пренебрежимо мал (Cohen's d ≈ 0.02)** —
практически значимых различий нет.
Ноутбук: `Project_2/notebooks/online_retail.ipynb`.

### Project_3 — Рандомизированные A/B-тесты (синтетика)
Два самодостаточных ноутбука (данные генерируются внутри, фиксированный seed):
- `ab_continuous.ipynb` — A/B на непрерывной метрике (средний чек): H0/H1, расчёт
  размера выборки и MDE, мощность, Welch t-тест, ДИ разницы, размер эффекта.
- `ab_conversion.ipynb` — A/B на конверсии: z-тест для пропорций и хи-квадрат,
  ДИ разницы долей, расчёт размера выборки под заданный MDE.
Папка: `Project_3/notebooks/`.

## Данные

Сырые CSV не хранятся в git. Скачайте их по инструкциям в:
- `Project_1/data/README.md` — Olist (Kaggle);
- `Project_2/data/README.md` — Online Retail II (UCI).

Project_3 данных не требует — они генерируются в самих ноутбуках.

## Как запустить

```bash
python -m pip install pandas numpy scipy matplotlib seaborn statsmodels jupyter nbconvert nbformat

# запуск конкретного ноутбука с сохранением результатов
python -m jupyter nbconvert --to notebook --execute --inplace Project_1/notebooks/01_eda.ipynb
```

Или откройте ноутбуки в Jupyter Lab / VS Code и выполните ячейки сверху вниз.

## Ключевые выводы

- **Project_1:** средний платёж по кредитной карте (~163 BRL) выше, чем по ваучеру
  (~66 BRL); различие значимо и практически заметно (d ≈ 0.45), но это наблюдательное
  сравнение — причинность не доказана.
- **Project_2:** различие среднего чека между UK и Германией статистически «значимо»
  лишь из-за огромного n; фактический размер эффекта ничтожен (d ≈ 0.02) — практической
  разницы нет. Хороший пример, почему p-value недостаточно.
- **Project_3:** на рандомизированных данных эффект детектируется корректно, а дизайн
  (случайный сплит + предрасчёт выборки/мощности) позволяет делать причинные выводы.

## Замечание о статистике

При больших выборках p-value почти всегда мал, поэтому вывод «p < 0.05» сам по себе
малоинформативен. Ориентируйтесь на **размер эффекта** и **практическую значимость**,
а для причинных выводов нужна **рандомизация**.
