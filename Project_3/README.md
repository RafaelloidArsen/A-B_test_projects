# Project 3 — Настоящие рандомизированные A/B-тесты (на синтетике)

В отличие от Project 1 и Project 2 (наблюдательные сравнения на реальных данных), здесь — **корректные рандомизированные A/B-тесты**: группы формируются случайным сплитом, эффект закладывается в данные, поэтому вывод причинный. Данные генерируются прямо в ноутбуках (фиксированный seed), скачивать ничего не нужно — папки `data/` нет.

## Ноутбуки

- **`notebooks/ab_continuous.ipynb`** — A/B на непрерывной метрике (средний чек): постановка H0/H1, расчёт размера выборки под заданный MDE и мощность 80%, случайный сплит, Welch t-тест, доверительный интервал разницы, размер эффекта, корректная интерпретация.
- **`notebooks/ab_conversion.ipynb`** — A/B на конверсии (доля): расчёт размера выборки под MDE в п.п., биномиальная генерация, z-тест для пропорций и хи-квадрат, доверительный интервал разницы долей, вывод.
